[CONTEXTO COMPLETO — PROYECTO RIPTIDE]

Soy desarrollador Android (Kotlin + Jetpack Compose), desarrollador web y tengo experiencia con Kotlin Multiplatform (KMP). Estoy desarrollando una app personal llamada Riptide en mi tiempo libre, partiendo de cero como proyecto propio.

---

CONCEPTO DE LA APP

App de productividad con ecosistema marino que crece con la constancia. La puntuación existe internamente pero nunca se muestra como número. El feedback es siempre emocional: mensajes, crecimiento visual del estanque, sensación de progreso sin métricas explícitas. La constancia construye algo bonito. El abandono lo pausa. Nunca lo destruye.

---

STACK TÉCNICO

- Kotlin Multiplatform con Compose Multiplatform (una sola UI para Android e iOS)
- Proyecto generado con el KMP Wizard de JetBrains (kmp.jetbrains.com)
- La estructura no tiene carpeta shared: todo vive en composeApp/src/
- commonMain: lógica de negocio, modelos, repositorios, ViewModels, UI
- androidMain / iosMain: implementaciones específicas de plataforma
- Persistencia MVP: Room (local, offline-first), versión 5
- IDs String (UUID) desde el primer día para facilitar sincronización futura
- Capa repositorio que abstrae el origen de datos
- Patrón MVVM

MODELOS DE DATOS (commonMain, Kotlin puro, sin Room)

WorkBlock: id (String), name (String), marineCategories (List<MarineCategory>),
  color (String hex), icon (String emoji), recurrence (Recurrence), isActive (Boolean)
  — marineCategories se asigna automáticamente por MarineCategoryAssigner, nunca visible al usuario

BlockCategory: blockId (String), category (MarineCategory)
  — tabla separada con PK compuesta (blockId, category) y FK CASCADE desde WorkBlock

Recurrence sealed class:
- None
- Weekly(slots: List<WeeklySlot>)

WeeklySlot: dayOfWeek (Int, 1=Lunes...7=Domingo), startTime (LocalTime?), endTime (LocalTime?)

MarineCategory enum: FISH, FLORA, CRUSTACEAN, MOLLUSK, PELAGIC

DayTask: id (String), blockId (String), date (LocalDate), title (String),
  estimatedMinutes (Int?), isCompleted (Boolean), completedAt (LocalDateTime?), order (Int)

DaySummary: id (String), date (LocalDate), score (Float 0.0-1.0, NUNCA visible),
  tasksTotal (Int), tasksCompleted (Int), streakDay (Int), feedbackMessage (String, sí visible)

BlockStreak: blockId (String), currentStreak (Int), lastActiveDate (LocalDate)

EcosystemState: id (String), category (MarineCategory), totalExperience (Int, NUNCA visible),
  currentLevel (Int), lastUpdated (LocalDateTime)

MarineCreature: id (String), ecosystemId (String), species (CreatureSpecies),
  nickname (String?), unlockedAtLevel (Int), experience (Int), creatureLevel (Int),
  unlockedAt (LocalDateTime)

CreatureSpecies enum (vinculada a MarineCategory):
- FISH: CLOWNFISH, ANGELFISH
- FLORA: BRAIN_CORAL, ANEMONE
- CRUSTACEAN: HERMIT_CRAB, LOBSTER
- MOLLUSK: STARFISH, SEA_URCHIN
- PELAGIC: MOON_JELLYFISH, MANTA_RAY

LÓGICA DE CATEGORÍAS MARINAS (MarineCategoryAssigner)

Las categorías se asignan automáticamente al crear/eliminar bloques. El usuario nunca las ve.

Distribución según número de bloques:
- 1 bloque  → 5 categorías (todas)
- 2 bloques → 3 + 3 (1 se repite)
- 3 bloques → 2 + 2 + 2 (1 se repite)
- 4 bloques → 2 + 1 + 1 + 1 (1 se repite)
- 5 bloques → 1 cada uno (sin repeticiones)

La experiencia acumulada en EcosystemState se mantiene intacta al redistribuir.

Se llama desde: DataSeeder.seedIfEmpty(), MainViewModel (insert/update/deleteBlockAndReassign),
BlockFormViewModel (saveBlock, deleteBlock).

UI — PANTALLA PRINCIPAL

Fondo gradiente oceánico: OceanDeep #0A1628 → OceanMid #1B3A6B → OceanLight #2E5F9E
Tarjetas frosted glass (blanco 20% opacidad)

WeekCalendar: 7 días navegables, swipe horizontal para cambiar semana,
  punto indicador en día actual, todas las DayCell con mismo ancho (weight(1f)),
  feedback visual al swipe (alpha animation).

Separador semitransparente entre calendario y lista de tareas.
Tareas tachadas al completarse, checkbox con color del bloque.
FAB 🐟 para ver estanque (siempre visible, no corta scroll).
Scroll de tareas con contentPadding bottom=80.dp

GESTOS unificados en Box exterior:
- Vertical hacia abajo → abre drawer
- Vertical hacia arriba → cierra drawer
- Horizontal izquierda/derecha → cambia día (solo si drawer cerrado)
Drawer se abre desde arriba con animación (Animatable drawerOffsetY).
Overlay oscuro semitransparente al abrir drawer, toque fuera cierra.

DRAWER (MainDrawer): baja desde arriba, fondo OceanDeep/OceanMid ~85% opacidad.
  Secciones: TAREAS (➕ Añadir tarea — pendiente), BLOQUES (lista + ➕ Añadir bloque).
  Asa visual en la parte inferior.
  Navega a BlockFormScreen al pulsar bloque o añadir bloque.
